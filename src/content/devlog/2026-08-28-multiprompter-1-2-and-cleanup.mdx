Multiprompter 1.2 shipped the boring Mac app pieces that make a tool feel less
like a prototype. The editor now has a real File menu with New, Open, Open
Recent, Save, and Save As. New, Open, and quit all respect unsaved changes, and
the toolbar got quieter because file actions belong in the system menu on macOS.

This release also added Sparkle in-app updates, a live appcast, a notarized DMG,
and a bumped Homebrew cask. I kept the sandbox on, which meant the update path
had to work with the same constraints as the real app instead of sneaking around
them.

Before starting auto-scroll, I did one more cleanup pass:

- held security-scoped file access for documents opened from recents
- guarded double submits in the license flow
- verified keychain writes before showing success
- cleared undo history after loading a file
- cached line indexing for smoother scroll math
- debounced rendered preview updates
- added a development-only license bypass for local builds

The release cut itself took about 25 minutes, which is exactly what I wanted.
Signing, notarization, the download, the appcast, and the cask are now boring
enough that future releases should be about the feature, not the ritual.

Next up is auto-scroll in 1.3. The app already has the hard part: one shared
scroll position across every window. Auto-scroll is just another thing that
moves that position.
